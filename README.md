# Mark Ralphael Tive — Estimating Portfolio

A responsive professional portfolio built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Lucide React, and Recharts.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Deploy to Vercel

Push this folder to a GitHub repository, import that repository at Vercel, and keep the automatically detected Next.js settings.

## Customize

- Replace `public/images/profile.jpg` with the preferred portrait.
- Update contact placeholders in `app/page.tsx`.
- Update site metadata in `app/layout.tsx`.
